# Sơ đồ khối nối dây — Eco-Smart Oasis

> ① = 5V Rail  │  ② = GND Rail  │  ③ = 3.3V Rail (từ chân 3V3 của ESP32)
> ══ = dây 5V  │  ── = dây GND/Signal  │  ·· = dây 3.3V

## Thanh nối chung (Rail) — Cách đấu thực tế

```
Dùng domino điện hoặc breadboard để tạo 3 thanh nối:

  ┌──────────────────────────────────────────────────────────────┐
  │  ① 5V Rail  ══╦══╦══╦══╦══╦══╦══                           │
  │               ║  ║  ║  ║  ║  ║                             │
  │             VIN ESP Relay Relay Servo ...                   │
  │                                                              │
  │  ② GND Rail ──┼──┼──┼──┼──┼──┼──                           │
  │               │  │  │  │  │  │                             │
  │            GND GND GND GND GND GND ...                     │
  │           (ESP)(Relay)(Servo)(Sensor)(DHT22)(Soil)(Rain)    │
  │                                                              │
  │  ③ 3.3V Rail ·┼··┼··┼··┼··                                 │
  │               │  │  │  │                                   │
  │             VCC VCC VCC VCC ...                             │
  │          (DHT22)(Soil)(Rain)(LDR-R10k)                      │
  └──────────────────────────────────────────────────────────────┘
```
